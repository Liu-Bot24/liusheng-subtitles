# 隐私说明

流声字幕用于在网页视频页面上生成翻译字幕。为了尽早发现视频来源，插件的页面脚本会在每个网页加载时运行；语音识别和翻译只在用户开始任务后进行。

## 处理的数据

插件可能处理以下数据：

- 当前标签页的网址、标题、简介、频道名、页面语言和视频时长。
- 网页自己加载的接口响应和媒体请求，用于从中找出媒体地址。这些内容只在本机浏览器内检查。
- 当前标签页中发现的媒体地址，例如 m3u8、mpd、mp4、m4s 或音频地址。
- 为抽取音频所需的有限请求信息，例如来源页面地址、媒体类型和必要的请求头。
- 用户在设置中填写的 ASR/翻译接口地址、模型名称和 API 密钥。
- 用户在任务入口选择的原音频语言。
- 用户在自定义 ASR 档案中选择的 VAD 过滤策略。内置 ASR 档案不使用这个选项。
- 浏览器内 Web FFmpeg 生成的临时音频切片和 ASR 音频分段。
- 浏览器内 Web FFmpeg 识别出的语音区间元数据，用于跳过无语音分段和过滤静音幻觉。
- 语音识别结果、翻译字幕、用户导入的字幕文件和插件自动缓存的字幕。
- 当前任务的阶段、分段状态和付费请求操作标识，以及语音识别/翻译服务返回的完整响应。FunASR 文件任务还会暂存服务返回的临时文件地址。这些信息用于在浏览器后台重启或消息确认丢失后恢复同一任务，避免重复提交付费请求。

## 数据用途

这些数据只用于发现网页视频媒体源、在浏览器内抽取临时音频、调用用户配置的语音识别/翻译服务，以及把生成的字幕显示回当前页面。

## 数据存储

- API 密钥保存在本机浏览器的扩展本地存储中，不同步到浏览器账号。
- 字幕缓存保存在本机浏览器的扩展 IndexedDB 中，用于下次打开同一网页链接时直接加载字幕。缓存用归一化后的页面和媒体身份来匹配；条目里保存的字幕数据还会记录生成任务时的原始页面地址和媒体地址，这些地址可能带有网站附加在链接上的 token、签名或来源追踪参数。插件会自动清理超过 30 天或超过 80 条的旧字幕缓存。
- 用户为 `file://` 本地视频主动选择文件后，Chrome 的 File System Access API 会把该文件的只读句柄，以及文件的完整本地路径、文件名、大小和修改时间保存在扩展本机 IndexedDB 中，供 offscreen 抽取器读取同一个文件，并在任务重试或重新抽取时避免重复选择。插件不会复制文件正文；读取权限由 Chrome 管理，权限失效时会要求用户重新选择。这些记录不会自动过期；卸载扩展或重置扩展数据会删除它们。
- 音频切片和 ASR 音频分段只作为任务过程数据使用，不作为长期音频归档。已结束任务的音频最多保留约 36 小时，音频缓存总量超过约 2 GB 时也会优先清理这部分数据。尚未结束的任务（包括中断后可以继续的任务）的音频不受这两项限制，会保留到任务结束，或保留到下文所述的 7 天任务记录期限，以便继续任务时不必重新下载。用户也可以在侧边栏提前清理。缓存仍完整时可用于继续任务、重试失败分段或重新 ASR；缓存缺失、损坏或已清理时不会继续复用，用户重新抽取后会重新下载或读取原媒体并生成新的音频。普通用户界面不提供额外的音频归档导出入口。
- 语音区间元数据只作为当前任务过程数据使用，不包含转写正文或 API 密钥。
- 当前标签页已发现的媒体地址和页面信息会复制一份到浏览器的会话存储中，用于插件后台重启后恢复候选列表。会话存储只在内存中，关闭浏览器即清除；标签页关闭或打开其他页面时，对应记录也会删除。这份副本不包含下载媒体所需的请求头。
- 任务和分段状态保存在扩展本机 IndexedDB 中；付费请求的完整响应和 FunASR 临时文件地址保存在扩展本机 Cache Storage 中。任务账本只保存模型配置档案引用，不复制 API 密钥。这些数据不会同步到浏览器账号，也不会发送给流声字幕开发者。
- 已完成、失败、取消或中断的任务记录和对应付费响应以 7 天为自动清理期限；浏览器下次运行维护任务时会删除到期数据。清理中断时，插件会保留一份只包含旧任务标识和本地缓存引用的清理记录，在后续维护中继续删除，不会按页面或任务前缀删除新任务的数据。
- 插件申请 `unlimitedStorage` 权限，避免浏览器在存储压力下驱逐仍用于任务恢复和付费响应重放的 IndexedDB/Cache Storage 数据。该权限只影响本机扩展存储；上述自动清理期限和侧边栏音频清理功能仍然有效。
- 插件不会把 API 密钥同步到浏览器账号。

## 数据共享

插件不会把数据发送给流声字幕开发者自有服务器。
当用户配置第三方或局域网语音识别、翻译模型时，音频分段、转写文本和待翻译字幕会发送给用户配置的服务地址。翻译请求还会附带当前页面的完整网址、标题、简介、频道名、页面语言和视频时长，作为翻译上下文。
在 X（Twitter）和哔哩哔哩页面，用户打开插件侧边栏后，插件会以当前网页的登录状态向这两个网站自己的接口查询视频信息，用于找到媒体地址；这些请求只发往网站本身。用户没有打开侧边栏时不会发出这类请求。
媒体下载可能需要当前网页请求里的有限请求头；这些头只留在后台/offscreen 下载链路中，候选列表不会把 `authorization` 返回给侧边栏界面。`Cookie` 不会进入候选或被脚本手写，跨域媒体下载时，由浏览器按当前登录状态自行附带 Cookie。
插件只向用户配置的服务地址发送该服务需要的请求字段；用户明确选择原音频语言时，会向 ASR 请求写入规范化后的 `language` 字段。`vad_filter` 这类非标准 ASR 字段只会发送给 `openapi.json` 确认支持或用户明确强制开启的兼容接口，不会附加到标准 OpenAI、Groq 或 xAI 请求上。VAD 过滤策略不是“关闭”时，插件可能读取自定义 OpenAI 兼容接口同一地址下的 `openapi.json` 能力说明；这个请求不带 API 密钥，也不上传音频。除 OpenAI、Groq、xAI 的官方地址外，第三方托管的兼容接口同样会被读取。
对自定义 OpenAI 兼容 ASR 接口，如果同一地址下的 `openapi.json` 明确声明支持 Whisper/faster-whisper 兼容抑制字段，插件可能随 ASR 请求发送这些字段以减少静音、音乐或片尾段幻觉；标准 OpenAI、Groq、xAI 请求不会附加这些非标准字段。
每批字幕先整批发送给翻译服务。返回无法解析的结果、整批失败或被服务方内容审核拦截时，插件会把这一批字幕逐级拆小后重新发送，尽量救回其余句子，每批增加的调用次数有固定上限。如果只漏掉部分译文，插件保留已成功的译文，只向用户配置的翻译服务补发缺失的句子。API 密钥无效、认证失败、余额或额度不足、限流和模型不存在等账户或配置错误不会拆分重发。最终仍失败的句子只保留原文并给出提示；整段都失败时，该段标记为失败，只保留原文供重试。用户可以在侧边栏对某一段重新翻译；只要浏览器后台还保留该任务的原文识别结果，重新翻译就不会重新识别语音。

## 权限说明

插件声明全站 host 权限，页面脚本会在每个网页加载早期运行，监听媒体请求并识别 m3u8、mpd、m4s、mp4 或音频源。该权限只用于媒体源发现、字幕挂载和当前页面视频状态读取；插件不会把网页内容发送给流声字幕开发者自有服务器。

插件声明 `unlimitedStorage` 权限，用于保护任务账本、临时音频和付费响应恢复证据不受普通扩展存储配额或压力驱逐影响。数据只保存在本机，并按前述规则清理。

## 导入与导出

用户可以把生成好的字幕导出为 SRT 文件，也可以从本地 SRT、VTT、ASS/SSA 或包含原文和译文字幕数组的 JSON 文件导入字幕。导出的 SRT 文件开头会写入来源页面的完整网址和流声字幕的网址。导出的文件由用户自行保存和管理，插件不会把导出文件上传到任何服务器。

## 删除数据

卸载扩展或重置浏览器扩展数据会移除浏览器内保存的模型配置、字幕缓存、任务账本、临时音频、付费响应缓存和待完成的本地清理记录。侧边栏也提供清理当前页面字幕缓存和当前任务音频缓存的入口。
